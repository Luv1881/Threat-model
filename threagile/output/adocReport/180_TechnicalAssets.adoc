= Identified Risks by Technical Asset
In total *35 potential risks* have been identified during the threat modeling process of which *0 are rated as critical*, *1 as high*, *16 as elevated*, *15 as medium*, and *3 as low*. 

These risks are distributed across *6 in-scope technical assets*. 
The following sub-chapters of this section describe each identified risk grouped by technical asset. 
The RAA value of a technical asset is the calculated "Relative Attacker Attractiveness" value in percent.
[[api-server]]
== [.HighRisk]#API Server: 16/16 unmitigated Risks#
=== Description
Node.js/Express REST API. Handles authentication (JWT/bcrypt), CRUD on notes, file uploads to MinIO. Bridges the frontend and backend networks. Single most security-critical component — compromise equals full data access.
