= Identified Risks by Technical Asset
In total *12 potential risks* have been identified during the threat modeling process of which *0 are rated as critical*, *0 as high*, *6 as elevated*, *6 as medium*, and *0 as low*. 

These risks are distributed across *6 in-scope technical assets*. 
The following sub-chapters of this section describe each identified risk grouped by technical asset. 
The RAA value of a technical asset is the calculated "Relative Attacker Attractiveness" value in percent.
